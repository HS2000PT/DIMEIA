# Counterbalancing plan

Half the participants see A first, half see B first, and the two conditions use
**different** alerts — otherwise the second condition would just be recall.

| Participant | Order | Condition 1 | Condition 2 |
|---|---|---|---|
| P01 | A→B | A: S1, S2, S3 | B: S4, S5, S6 |
| P02 | B→A | B: S4, S5, S6 | A: S1, S2, S3 |
| P03 | A→B | A: S1, S2, S3 | B: S4, S5, S6 |
| P04 | B→A | B: S4, S5, S6 | A: S1, S2, S3 |
| P05 | A→B | A: S1, S2, S3 | B: S4, S5, S6 |
| P06 | B→A | B: S4, S5, S6 | A: S1, S2, S3 |
| P07 | A→B | A: S1, S2, S3 | B: S4, S5, S6 |
| P08 | B→A | B: S4, S5, S6 | A: S1, S2, S3 |
